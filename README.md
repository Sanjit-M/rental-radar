# Rental Radar

Rental Radar is an automated rental post aggregator, cross-group deduplicator, and weekday peak scooter commute scoring platform tailored for engineers working at Prestige Tech Park (PTP), Kadubeesanahalli, Bangalore.

---

## 1. Core Architecture & Features

### A. Geolocation & OpenStreetMap View
- Uses Leaflet with CartoDB Dark Matter tiles (zero external API keys or credit cards required).
- Plots known gated societies (Sobha Iris, Sobha Hibiscus, Assetz East Point, Goyal Orchid Lakeview, Prestige Sunnyside, Divyasree 77 East) with custom score markers.
- Interactive popups with rent, weekday commute metrics, author information, and one-click contact buttons.

### B. Cross-Group Deduplication Engine
- Detects duplicate listings cross-posted across multiple Bangalore Facebook groups using:
  1. Identical contact phone numbers and rent.
  2. Matching author names and post body text similarity (Jaccard 3-gram index).
- Consolidates duplicates into a single canonical listing card with a `Seen in X groups` badge.

### C. Weekday Peak Commute Engine
- Models two-way weekday peak scooter traffic to Prestige Tech Park (Kadubeesanahalli Gate):
  - Inbound: 11:00 AM – 1:00 PM IST (1.30x baseline multiplier).
  - Outbound: 4:00 PM – 6:00 PM IST (1.65x baseline multiplier).
  - Panathur Railway Underpass Penalty: +8 minutes for bottleneck routes.

### D. Multi-Factor 0–100 Rating Engine
- Base Score: 50 points.
- Low Rent (<= 25k): +20 pts.
- Zero Brokerage: +15 pts (Strict Brokerage: -30 pts).
- Deposit <= 2.2x monthly rent: +10 pts (Deposit > 2.2x rent: -15 pts).
- Gated Community: +15 pts.
- Swimming Pool: +15 pts.
- 100% Power Backup: +10 pts.
- Attached Washroom: +10 pts (Shared Washroom: -5 pts).
- Walking Proximity to PTP (<500m): +15 pts.
- Bachelor / Male Match: +10 pts (Strictly Female Only: -25 pts).
- Vegetarian-Only Restriction Penalty: -50 pts (caps maximum score).

### E. Backend Database Pagination
- Server-side SQL pagination (`LIMIT` and `OFFSET`) on SQLite and Turso Cloud.
- Recency filtering: `Past 1 Hour`, `Past 3 Hours`, `Past 6 Hours`, `Past 12 Hours`, `Past 24 Hours`, `Past 7 Days`, and `All Time`.

## 2. Local Setup & Development

### Prerequisites
- Node.js >= 22.0.0
- pnpm >= 9.0.0

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Sanjit-M/rental-radar.git
cd rental-radar

# 2. Install dependencies
pnpm install

# 3. Authenticate Facebook Session (Opens in Helium / Default Browser)
pnpm auth

# 4. Start local development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 3. Cloud Deployment (100% Free Tier)

### Step 1: Create Turso Cloud Database
1. Sign up at [turso.tech](https://turso.tech).
2. Create a database:
   ```bash
   turso db create rental-radar
   turso db show rental-radar --url
   turso db tokens create rental-radar
   ```

### Step 2: Deploy to Vercel
1. Import repository on [vercel.com](https://vercel.com/new).
2. Add Environment Variables in Project Settings:
   - `TURSO_DATABASE_URL` = `libsql://rental-radar-xxx.turso.io`
   - `TURSO_AUTH_TOKEN` = `[Your Turso Auth Token]`
   - `DASHBOARD_PASSCODE` = `[Optional Secret PIN]`
3. Ensure **Settings -> Deployment Protection -> Vercel Authentication** is **Disabled**.

### Step 3: Configure 24/7 Hourly Scraper (GitHub Actions)
Add these secrets to GitHub -> **Settings -> Secrets and variables -> Actions**:
- `FB_SESSION_STORAGE`: Base64 string generated by `pnpm auth`.
- `TURSO_DATABASE_URL`: Turso cloud database URL.
- `TURSO_AUTH_TOKEN`: Turso authorization token.
